## 当前外部依赖

1. 各分类凭据模板及真实写入联调。Silicon 与 TCP Red / Colin 均已实现 OpenAI type=1 普通 Key 映射，TCP Red 读取接口已实测；其余模板在列表中标记待适配。
2. 卖家渠道消耗接口的来源 ID、时间、分页、单位、增量/退款规则、账期边界和权限，当前不会使用个人消费日志替代卖家收入依据。
3. 持久任务中的测试后启用流程、RPM 执行机制及代理字段。Colin 测试接口已从公开客户端识别，但尚未接入任务状态机；未实现的能力不启用。
4. 业务确定的支付换算依据、各对象分类折扣、历史补算范围。初始化不生成虚拟交易或默认 1:1 规则。
5. 正式部署域名/HTTPS、备份保留期和容量压测。尚未宣称达到20站点、5,000渠道及20并发的性能目标。

系统未使用项目内账号密码表，也没有向真实站点创建、修改或删除渠道。
